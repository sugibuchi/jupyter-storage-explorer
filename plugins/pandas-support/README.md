# jupyter-storage-explorer-pandas-support

pandas support for Storage Explorer,
the [Jupyter Storage Explorer](https://github.com/sugibuchi/jupyter-storage-explorer) plugin for
pandas as an engine: the data browser on the first rows of Parquet, CSV, JSON Lines and Excel files, and code loading
them.

## Installation

```bash
pip install "jupyter-storage-explorer[pandas]"          # the plugin and its libraries
pip install "jupyter-storage-explorer[pandas-support]"  # the plugin only, with the libraries you have
```

The libraries are not the plugin's dependencies, so that installing it never changes those of a shared environment.
The first command installs them, as does `jupyter-storage-explorer-pandas-support[full]`:

| Library    | Needed for                            |
|------------|---------------------------------------|
| `pandas`   | Mandatory: the engine                 |
| `pyarrow`  | Parquet files, read by pandas         |
| `openpyxl` | Excel workbooks (`.xlsx`), read by pandas |

Without `pyarrow` or `openpyxl`, the other formats still work.

### Prerequisites

- pandas reads cloud storage through fsspec, with the storage's package, e.g. `s3fs` or `adlfs`.
- The code needs credentials for cloud storage: see [Authentication](https://github.com/sugibuchi/jupyter-storage-explorer/blob/main/plugins/pandas-support/README.md#authentication).

### Authentication

The data browser reads through the explorer's filesystems, with their credentials: it needs nothing more.

The code reads with pandas, which opens its own fsspec filesystems. Give their credentials as `storage_options`, one
per storage with `by_protocol`:

```python
from jupyter_storage_explorer import StorageExplorer
from jupyter_storage_explorer.engine import by_protocol

StorageExplorer(
    filesystems={
        "Lake": "abfs://lake@account.dfs.core.windows.net",
        "Personal": "s3://my-bucket",
    },
    engine_options={
        "pandas": {
            "*": by_protocol(
                {
                    "abfs": {"storage_options": {"anon": False}},
                    "s3": {"storage_options": {"profile": "personal"}},
                }
            ),
        },
    },
)
```

The storage options are those of the storage's fsspec filesystem:

- [`adlfs`](https://fsspec.github.io/adlfs/api/): Azure Storage. `anon: False` uses azure-identity's default
  credential.
- [`s3fs`](https://s3fs.readthedocs.io/en/latest/api.html#s3fs.core.S3FileSystem): S3, e.g. with an AWS profile.
- [`gcsfs`](https://gcsfs.readthedocs.io/en/latest/api.html#gcsfs.core.GCSFileSystem): Google Cloud Storage.

In configuration files, `engine_options()` returns the same engine options: in `common.py` for every explorer, or in
`launcher.py` for the launcher's tabs.

```python
def engine_options():
    return {
        "pandas": {
            "*": by_protocol({"abfs": {"storage_options": {"anon": False}}}),
        },
    }
```

## Plugin options

`plugin_options` gives the plugin's options:

```python
StorageExplorer(
    "s3://my-bucket/lake", plugin_options={"pandas-support": {"priority": 10}}
)
```

In configuration files, `plugin_options()` gives them: in `common.py` for every explorer, or in `launcher.py` for
the launcher's tabs.

```python
def plugin_options():
    return {"pandas-support": {"enabled": False}}
```

| `priority` | lowest  | Plugins of a higher priority come first: their actions, operations and mappers are tried before the others'. Equal ones by key. |

## Engine options

The plugin's options, in `engine_options["pandas"]` (by format, or `"*"` for all), for the data browser and the code:

```python
StorageExplorer(
    "s3://my-bucket/lake",
    engine_options={
        "pandas": {
            "*": {"storage_options": {"anon": False}},
            "csv": {"na_values": ["NA"], "dtype_backend": "pyarrow"},
            "excel": {"sheet_name": "Summary"},
        },
    },
)
```

Every format takes:

<!-- options: jupyter_storage_explorer_pandas_support.PandasOptions -->
| Option            | Default | Meaning                                                                                                                                                        |
|-------------------|---------|----------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `storage_options` | `None`  | pandas' `storage_options`, `fsspec.open`'s keyword arguments, in the code. The data browser reads through the explorer's filesystem, with its own credentials. |

The other options are each format's reader's arguments, of the same names, with their descriptions from pandas' API
documentation. Those not set are not passed, so pandas' defaults, shown below, apply, except where the explorer sets
its own. The data browser reads at most `max_memory_rows` rows (see `view_limits`), of each sheet of a workbook.
