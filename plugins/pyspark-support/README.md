# jupyter-storage-explorer-pyspark-support

PySpark support for Storage Explorer,
the [Jupyter Storage Explorer](https://github.com/sugibuchi/jupyter-storage-explorer) plugin for
PySpark as an engine: the data browser on Spark DataFrames of Delta Lake tables, Parquet, CSV and JSON Lines, and code
loading them.

## Installation

```bash
pip install "jupyter-storage-explorer[pyspark]"          # the plugin and its libraries
pip install "jupyter-storage-explorer[pyspark-support]"  # the plugin only, with the libraries you have
```

The libraries are not the plugin's dependencies, so that installing it never changes those of a shared environment.
The first command installs them, as does `jupyter-storage-explorer-pyspark-support[full]`:

| Library       | Needed for                                                       |
|---------------|------------------------------------------------------------------|
| `pyspark`     | Mandatory: the engine                                            |
| `delta-spark` | Delta Lake tables                                                |
| `pyarrow`     | Mandatory: the data browser reads Spark's rows into PyArrow       |

Without `delta-spark`, the other formats still work. For Databricks Connect, use
[databricks-support](https://github.com/sugibuchi/jupyter-storage-explorer/blob/main/plugins/databricks-support/README.md)
instead: with Databricks Connect installed, this plugin's engine is not offered.

### Prerequisites

- The plugin expects Spark to reach your storage already, e.g. through
  [`spark-defaults.conf`](https://spark.apache.org/docs/latest/configuration.html#overriding-configuration-directory)
  or [Databricks unified authentication](https://docs.databricks.com/aws/en/dev-tools/auth/unified-auth).
- `session_options` in [Engine options](https://github.com/sugibuchi/jupyter-storage-explorer/blob/main/plugins/pyspark-support/README.md#engine-options) can add Spark properties. With a session already running,
  only those Spark can change at run time apply.
- Spark reads the items' URLs itself. `supported_protocols` in [Engine options](https://github.com/sugibuchi/jupyter-storage-explorer/blob/main/plugins/pyspark-support/README.md#engine-options) says which storages it
  reaches, e.g. `["s3a"]` for a cluster configured for S3 only.

## Plugin options

`plugin_options` gives the plugin's options:

```python
StorageExplorer(
    "abfs://lake@myaccount.dfs.core.windows.net/raw",
    plugin_options={"pyspark-support": {"priority": 10}},
)
```

In the launcher's tabs, `plugin_options()` in `launcher.py` gives them:

```python
def plugin_options():
    return {"pyspark-support": {"enabled": False}}
```

| Option     | Default | Meaning                                                                                                  |
|------------|---------|----------------------------------------------------------------------------------------------------------|
| `enabled`  | `True`  | Whether explorers use the plugin. `False`: not even imported.                                            |
| `priority` | lowest  | Plugins of a higher priority come first: their actions are tried before the others'. Equal ones by key.  |

## Engine options

The plugin's options, in `engine_options["pyspark"]` (by format, or `"*"` for all), configure the Spark session and
the reader, for the data browser and the code:

```python
StorageExplorer(
    "abfs://lake@myaccount.dfs.core.windows.net/raw",
    engine_options={
        "pyspark": {
            "*": {
                "session_options": {
                    "spark.sql.extensions": "io.delta.sql.DeltaSparkSessionExtension",
                    "spark.sql.catalog.spark_catalog": "org.apache.spark.sql.delta.catalog.DeltaCatalog",
                },
            },
            "csv": {"null_value": "NA", "mode": "DROPMALFORMED"},
            "delta": {"version_as_of": 3},
        },
    },
)
```

Every format takes:

| Option            | Default | Meaning                                                                                                                                                                                                                                                        |
|-------------------|---------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `session_options` | None    | Spark configuration, `SparkSession.builder.config(key, value)` for each. With a session already running in the kernel, only what Spark can change at run time applies.                                                                                         |
| `reader_options`  | None    | `spark.read.option(key, value)` for each: options not listed below, e.g. Spark's [generic file source options](https://spark.apache.org/docs/latest/sql-data-sources-generic-options.html) (`{"recursiveFileLookup": True}`). They override the options below. |
| `supported_protocols` | `SPARK_PROTOCOLS` | The URL schemes Spark reads, as Spark names them: by default `file`, `hdfs`, `s3a`, `gs`, `abfss`, `abfs`, `wasbs`, `wasb` and `dbfs`. Items elsewhere, e.g. on SFTP, are neither viewed nor given code with Spark. `None`: any. |

The other options are each format's reader options, from Spark's and Delta Lake's documentation, in snake case. Those
left unset (None) are left to Spark, whose defaults are shown.

| `timestamp_as_of` | (none)  | Loads the table as it was at a point in time. Only date or timestamp strings are accepted, e.g. `"2019-01-01"` or `"2019-01-01T00:00:00.000Z"`. |
